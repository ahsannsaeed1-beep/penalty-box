# PENALTY BOX — Website Concept

Website concept for **PENALTY BOX**, an ice hockey rink food concession stand at 2330 Lindsay St, Regina SK S4N 3C4, Canada.

Premium sports-food brand site: cinematic hero ("BIG GAME ENERGY. BIGGER BITES."), THE LINEUP menu with working category filters, Fan Favourites, the Penalty Box experience, three game-day specials, gallery with lightbox, and a "Catch Us at the Rink" location section. Colours: deep black, charcoal, ice white, bold arena red, metallic silver.
